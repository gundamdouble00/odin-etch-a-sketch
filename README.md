# [Etch-a-Sketch](https://www.theodinproject.com/lessons/foundations-etch-a-sketch) Project

This is a project in JavaScript Basis part of [The Odin Project](https://www.theodinproject.com/). This project helps us improve DOM manipulation skills.

I use Bun (1.4.2 version) to compile TypeScript to JavaScript. I choose TypeScript to code because it has types, it helps the development process becomes easier.

The command used to compile TypeScript to JavaScript:
```shell
bun build ./app.ts --outfile ./dist/app.js
```

*You can interact my result through this link: [odin-etch-a-sketch](https://gundamdouble00.github.io/odin-etch-a-sketch/).*
